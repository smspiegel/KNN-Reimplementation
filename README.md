# K-Nearest Neighbours Algorithm (KNN)
## Description
This is a repo to reimplement the KNN algorithm from scratch, only using numpy for operations, and matplotlib where necessary to visualize.

## Datasets:
The algorithm will be tested on the (Iris dataset)[https://archive.ics.uci.edu/dataset/53/iris] as well as the (GSE35988)[https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE35988] Prostate Cancer dataset from the Gene Expression Omnibus (GEO)[https://www.ncbi.nlm.nih.gov/geo/] part of the National Center for Biotechnology Information (NCBI)[https://www.ncbi.nlm.nih.gov]
